How detection works

  1. Hash signatures: the SHA-256 of a file is compared with known-bad lists in signatures/*.hashes.
  2. Pattern rules: byte or text patterns from signatures/patterns.json.
  3. Heuristics: scores suspicious traits such as double extensions, disguised or packed executables, obfuscated scripts and Office macros.
  4. Archives: the same checks run on each file inside a .zip.
  5. ClamAV (optional): a second opinion if ClamAV is installed.

Quarantine

Quarantined files are moved into Sentinel's vault, scrambled and made non-executable, so they can't run. Restoring a file also adds its hash to the allowlist so it isn't flagged again.

Web protection

Check a link

The link is checked offline from its text alone. It's never opened, and nothing is sent anywhere. "No obvious warning signs" isn't a guarantee: new phishing sites can look completely normal.

Blocked domains

Links to these domains (and their subdomains) are flagged as dangerous, and the network monitor alerts if any program connects to them.
